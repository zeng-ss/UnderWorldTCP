### 5. `LoginServer\Ctrl\PlayerSceneMgr.cs`

**关键 bug 修复**：原来 `OnPlayerEnter` 每次（每 100ms）都会 `new PlayerSceneInfo` 覆盖旧数据，导致坐标永远是 (0,0,0)。改为：已存在只更新会话信息，不重置位置：

```csharp
public void OnPlayerEnter(int roleId, int sessionId, string nickname)
{
    if (_players.TryGetValue(roleId, out PlayerSceneInfo info))
    {
        info.SessionId = sessionId;
        info.Nickname = nickname;
        _sessionToRole[sessionId] = roleId;
        return;
    }
    // ...不存在才创建并打日志
}
```

新增位置更新方法（新玩家进场时广播已有玩家坐标要用）：

```csharp
public void UpdatePosition(int roleId, float posX, float posY, float posZ, float rotationY)
{
    if (_players.TryGetValue(roleId, out PlayerSceneInfo info))
    {
        info.PosX = posX; info.PosY = posY; info.PosZ = posZ; info.RotationY = rotationY;
    }
}
```

### 6. `LoginServer\Ctrl\RoomMgr.cs`

`StartGame` 增加服务端校验，防止客户端绕过 UI 强行开始：

foreach (var p in room.Players)

## 六、验证流程

1. 客户端 A 创建房间 → 客户端 B 加入 → 双方都能看到 2 人列表。
2. B 勾选准备 → **A 的列表里 B 显示已准备**，A（房主）出现开始按钮。
3. B 未准备时 A 点开始 → 服务端拒绝（日志：玩家未准备）。
4. A 点开始 → 双方同时进入 GameScene → **互相能看到对方**（蓝色胶囊体），移动实时同步。
5. B 直接关闭客户端 → A 收到玩家离开通知，胶囊体销毁；B 重新登录可以正常再建/加房间。
